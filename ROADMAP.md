# Roadmap / نقشه راه

This roadmap is a set of ideas, **not delivery promises**. Suggestions and pull requests are welcome. Priorities depend on bug reports and maintenance capacity.

## Next candidates / پیشنهادهای بعدی

- **Preview before download**: scan accessible board metadata, show select/deselect controls for media, then download selected Pins.
- **English desktop UI**: bilingual localization rather than just translated documentation.
- **Real release QA**: Windows 10/11 VM tests, onedir executable smoke tests, signed builds if feasible.
- **Better progress clarity**: separate board scan/download states and explain unknown totals; avoid fake percentages.
- **Gallery experience**: keyboard navigation, larger image previews, polished loading/empty/error states.
- **Updater UX**: better UI for version checking, ideally with a safe explicit user-approved update process for EXE installs.
- **Accessibility**: focus-visible polish, screen reader checks, high-contrast alternative, reduced-motion support.

If you want to contribute, open a Feature request describing the user scenario, expected behavior and technical constraints. Do not request access-control bypasses or authentication circumvention.
