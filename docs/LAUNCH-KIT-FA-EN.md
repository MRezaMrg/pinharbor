## Short English launch post

**Introducing PinHarbor — a local board-media downloader for Pinterest.** Save accessible images and videos from boards, organize multiple downloads, and browse the results in a local media library. PinHarbor is open source, uses a burgundy/rose desktop UI, and now includes English and Persian documentation. The Windows portable package will be available as a GitHub Release after its build and real-world Windows verification. Independent project; not affiliated with Pinterest. Only download content you're permitted to use.

## Public FAQ — honest answers

**Does it download all pins?** It attempts accessible media supported by the upstream engines; private or unavailable items may fail. No completeness guarantee.  
**Does it require a Pinterest password?** No. Authenticated downloads can optionally use local browser cookies.  
**Is there a ready EXE?** The workflow builds a Windows ZIP on a tagged GitHub Release; verify the asset exists before promising a download.  
**Is it translated into English?** Documentation yes; UI currently Persian.  
**What is the license?** PinHarbor code is MIT; dependencies and downloaded media have separate rights and terms.
