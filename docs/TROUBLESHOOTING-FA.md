# رفع خطاهای رایج (فارسی)

| مشکل | راهکار |
|---|---|
| برنامه در اجرا بسته می‌شود یا Python پیدا نمی‌شود | Python 3.10+ نصب کنید؛ فایل `Run on Windows.bat` را از پوشه استخراج‌شده و قابل‌نوشتن اجرا کنید. |
| خطا در نصب وابستگی‌ها | اینترنت، پراکسی/فایروال، فضای دیسک و دسترسی pip را بررسی کنید و دوباره فایل اجرا را باز کنید. |
| لینک نامعتبر | لینک خود **بورد یا سکشن** را بدهید؛ لینک یک پین تکی یا صفحه جست‌وجو پذیرفته نیست. |
| خطای 403 یا هیچ فایل پیدا نشد | بورد ممکن است خصوصی باشد یا ورود لازم داشته باشد. در صورت داشتن دسترسی، در مرورگر وارد حساب شوید و همان مرورگر را انتخاب کنید. |
| خطای 429 | پینترست درخواست‌ها را محدود کرده؛ مکث را بیشتر کنید و مدتی بعد دوباره تلاش کنید. |
| دانلود ویدیو ناموفق است | برخی ویدیوها در دسترس نیستند؛ نسخه‌های `gallery-dl` و `yt-dlp` را با `Update Engines.bat` در نسخه سورسی به‌روز کنید. |
| فایل تکراری دانلود نمی‌شود | طبیعی است؛ آرشیو SQLite فایل‌های موفق قبلی را ثبت می‌کند. |
| درصد پیشرفت عجیب است | درصد مربوط به بوردهای پردازش‌شده است، نه همه پین‌های داخل بورد. |
| خطای پوشه خروجی | محل قابل‌نوشتن دیگری انتخاب کنید و فضای خالی را بررسی کنید. |
| خروجی EXE اجرا نمی‌شود | تمام پوشه `dist/PinHarbor` شامل `_internal` را با هم منتقل کنید. |
| فونت فارسی مناسب نیست | فونت وزیرمتن را روی ویندوز نصب کنید و نرم‌افزار را مجدداً باز کنید. |
| آپدیت خطا می‌دهد | نسخه قبلی را ببندید، بسته جدید را جداگانه استخراج کنید و **پوشه نصب سورسی** را برای آپدیت انتخاب کنید. |

برای گزارش باگ نسخه برنامه، نسخه Windows، گام‌های بازتولید و متن گزارش پاک‌سازی‌شده را ارائه دهید. هیچ‌وقت رمز، کوکی، توکن یا اطلاعات پراکسی را منتشر نکنید.
