# PinHarbor — Brand guide / راهنمای برند

**Public name:** PinHarbor  
**Persian transliteration:** پین‌هاربر  
**Product line:** Board media, beautifully organized.  
**Descriptor:** Desktop Pinterest board media downloader and local library.

## Positioning

A calm, reliable place to collect and revisit board references, not a scraping service. Keep claims precise: "accessible media", "local library", "bulk board downloads"; avoid "download everything guaranteed" and "official Pinterest app".

## Color tokens

| Token | Hex | Usage |
|---|---|---|
| Near Black | `#120A11` | Core dark background |
| Burgundy | `#721F43` | Brand identity, control emphasis |
| Pastel Rose | `#F0B6CB` | Highlight, positive accents |
| Pale Text | `#FFF2F7` | Primary light text |
| Muted Rose | `#D0B4C1` | Secondary text |

## Iconography

Icon shows a harbor/safe archive for media cards, a downward arrow and a subtle wave. Original artwork (generated for this project), *not* Pinterest's official logo. Preferred rounded-square version in `assets/pinharbor-icon-512.png`; Windows icon in `assets/pinharbor-icon.ico`.

## Typography

Desktop UI: select **Vazirmatn** if installed, otherwise a readable system font. English marketing/docs can use system sans-serif. No commercial fonts or font binaries are included.

## Suggested GitHub description

**EN:** `A desktop Pinterest board media downloader with download queues, a local gallery and safe updates. Built with Python & PySide6.`

**FA:** `دانلود و مدیریت تصاویر و ویدیوهای بوردهای پینترست با صف دانلود، کتابخانه محلی و آپدیت ایمن.`

## Copy reminders

Explicitly state: independent, unofficial, local-first (but does make Pinterest network requests), accessible content only, Persian UI / bilingual docs, no compiled EXE provided until a Windows release actually exists.
