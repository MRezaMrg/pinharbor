# Publish PinHarbor to GitHub (guided path)

1. Extract the **`PinHarbor-v2.5.0-GitHub-Repository.zip`** into a new folder. This is the curated source distribution, not a compiled executable.
2. Install Python 3.10+, Git and [GitHub CLI](https://cli.github.com/). Run `gh auth login` and configure a public Git commit name/email (GitHub's noreply address is supported).
3. Double-click **`Publish to GitHub.bat`**, enter `pinharbor` or `OWNER/pinharbor`, select public/private, and type `PUBLISH` to confirm. The script only stages the explicit source-file allowlist, so it does **not** upload personal downloads, session settings or cookies. It will not create a release or tag automatically.
4. Open the repository **Actions** tab and confirm that the tests, offscreen Qt smoke test and Windows EXE packaging passed. The Windows build is downloadable as a workflow artifact even before the public release.
5. **After manual Windows and real-board QA**, run `git tag v2.5.0` followed by `git push origin v2.5.0`. The workflow creates a **draft** release with Windows portable, source, update ZIPs and checksums. Review the draft and publish it explicitly.

To inspect the intended upload without changing anything, run:

```powershell
python tools/github_publish.py --repo pinharbor
```

To publish intentionally:

```powershell
python tools/github_publish.py --repo pinharbor --execute
```

For users without Python, distribute the CI-produced **Windows-portable.zip**, not GitHub's autogenerated “Source code (zip)”. Unzip the entire archive and launch `PinHarbor/PinHarbor.exe`.

**Boundaries:** The Update ZIP applies to older **source-based** installations, not the Windows EXE distribution. A successful offline test is not evidence that every Pinterest video is downloadable. See `docs/RELEASE-CHECKLIST.md` for real-system verification.
