# انتشار PinHarbor 2.5.0 — پایداری و انتشار ساده‌تر

این نسخه با حفظ سازگاری صف، تنظیمات و آرشیو دانلود نسخه‌های ۲.x، مسیر راه‌اندازی و آپدیت و انتشار در GitHub را بهبود می‌دهد.

- بررسی SHA-256 تمام فایل‌های بسته آپدیت پیش از جایگزینی فایل‌های برنامه.
- تشخیص تغییر نیازمندی‌های Python و بازآماده‌سازی وابستگی‌ها در اجرای بعدی.
- اعتبارسنجی زنده لینک‌های بورد، راهنمای سریع و تست آفلاین آمادگی دانلود.
- حذف تصاویر داخلی نرم‌افزار از گالری در حالت پیش‌فرض ذخیره کنار برنامه.
- انتشار کنترل‌شده در GitHub با فایل `Publish to GitHub.bat` و توضیحات دوزبانه.
- آزمون واحد در Windows/Linux با Python 3.10/3.12 و تست ابتدایی رابط Qt در Windows CI.
- جمع‌آوری مجوزهای قابل بازیابی از وابستگی‌ها برای بررسی حقوقی بسته ویندوز.

**توجه:** فایل آپدیت فقط برای نصب‌های سورسی است. بسته ویندوز مستقل از Python پس از اجرای موفق GitHub Actions ساخته می‌شود. پیش از انتشار Stable، تست واقعی Windows، دریافت بورد زنده و رعایت مجوزهای کتابخانه‌های ثالث ضروری است. Release ابتدا در وضعیت **Draft** تولید می‌شود.
